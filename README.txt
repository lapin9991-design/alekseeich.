ПЕРСОНАЛЬНЫЙ САЙТ — ВЕРСИЯ 1
1. Распакуйте ZIP полностью. Откройте index.html двойным щелчком.
2. Для изменения информации откройте data.js через Блокнот. Меняйте текст внутри кавычек. Сохраните Ctrl+S и обновите сайт Ctrl+R. Не удаляйте запятые и скобки.
3. Для нового мероприятия скопируйте строку с мероприятием внутри events, включая фигурные скобки и запятую между записями. Измените title (название), date (ГГГГ-ММ-ДД), image (путь к фото), description (кратко), details (подробно). Сегодняшние события считаются предстоящими.
4. Скопируйте свои фотографии в images, например photo.jpg. Укажите images/photo.jpg в data.js. Для галереи добавьте запись по образцу в gallery. Все имена файлов должны совпадать точно.
5. Бесплатная публикация: создайте аккаунт GitHub, публичный репозиторий, загрузите содержимое папки сайта (не ZIP), включая images. Settings > Pages > Deploy from a branch > main > / (root) > Save. После публикации откройте выданную ссылку. Не размещайте секретные данные в публичном репозитории.
